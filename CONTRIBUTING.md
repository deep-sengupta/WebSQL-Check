# Contributing to WebSQL-Check

Thanks for helping improve the project!

### How to Contribute

**1. Fork** the repository<br>
**2. Create** a new branch<br>
**3. Make** your changes<br>
**4. Test** your changes<br>
**5. Submit** a pull request

## Guidelines

Keep contributions clean, focused, and consistent with the existing code.

For bug reports, include clear steps to reproduce the issue.
