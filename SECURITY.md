# Security Policy

> Please use WebSQL-Check only for authorized security testing.

### Reporting Security Issues

Found a security vulnerability in the project?

Please report it privately to the project maintainer instead of opening a public issue.

Include:

* **Issue:** What is the problem?
* **Reproduction:** How can it be reproduced?
* **Impact:** What can it affect?
* **Evidence:** Logs, screenshots, or relevant details.

## Responsible Disclosure

Please give the maintainer reasonable time to review and address the issue before sharing it publicly.

Thank you for helping
